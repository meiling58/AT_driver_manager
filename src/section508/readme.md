# Section 508
Section 508 is a federal law that requires modern technology to be accessible 
to people with disabilities. If you are working in automation, 
software development, or government contracting, understanding 
these standards is essential for ensuring that digital products—ranging 
from websites to PDF documents—are usable by everyone.


What is Section 508?Section 508 is part of the Rehabilitation Act of 1973. 


The Technical Standards (WCAG): In 2017, Section 508 was "refreshed" to align with the Web Content Accessibility Guidelines (WCAG) 2.0. Specifically, most compliance efforts target WCAG 2.0 Level AA success criteria.

Requirments:
- Perceivable: Information must be presentable in ways users can perceive (e.g., alt-text for images, captions for video).
- Operable: Interface components must be navigable (e.g., keyboard-only navigation, no flashing content that causes seizures).
- Understandable: Information and the operation of the UI must be clear (e.g., predictable web pages, input assistance).
- Robust: Content must be compatible with assistive technologies like screen readers (e.g., using valid HTML tags).


Scope of Compliance
- Software Applications: Both web-based and desktop applications.
- Hardware: Copiers, printers, and kiosks.
- Digital Documents: PDFs, Word docs, Excel sheets, and PowerPoint presentations.
- Multimedia: Training videos and webinars.


Section 508:
- Primary Target: Federal Agencies & Their contractors
- Focus: Electronic & Information Tech (EIT)
- Standard: Explicitly follows WCAG 2.0
